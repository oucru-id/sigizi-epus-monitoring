Monitoring pathway

The deletion registry is an exclusion reference. It is not unioned into ANC, INC, PNC, pregnancy, or delivery totals.

ANC, INC, and PNC readiness

ANC

Uses retained DAFTAR_IBU_HAMIL and ANC records. Source-record volume, pregnancies with source evidence, and pregnancies with explicit ANC dates stay as separate measures.

INC

Uses retained KOHORT_IBU and KOHORT_NIFAS records. Source rows, pregnancies with delivery evidence, and canonical delivery events must not be combined into one denominator.

PNC

KOHORT_NIFAS confirms source availability. KF1-KF4 coverage is intentionally pending until a curated PNC visit date and visit-stage contract is approved.

Deleted-pregnancy exclusion

A SIGIZI clinical row is excluded only when it matches the same pregnancy in the deletion registry:

  1. Matching usable identifier plus an exactly matching pregnancy anchor; or
  2. when an identifier is unavailable on either side, exact normalized name, maternal birth date, and pregnancy anchor.

The source anchor is HPHT, falling back to HPL minus 280 days only when HPHT is missing. Conflicting usable identifiers block the name-based fallback. A later pregnancy for the same mother remains eligible, and independent EPUS or hospital evidence is not removed.

Denominator rules

  • Raw/retained source records measure source volume.
  • t_sigizi_pregnancy_episode_v3_3 measures canonical SIGIZI pregnancies.
  • An ANC registration is not automatically an ANC encounter.
  • An INC source record, a pregnancy with delivery evidence, and a canonical delivery event are different grains.
  • PNC visits and KF1-KF4 cannot be reported until the visit-level adapter is explicitly defined.
  • All displayed tables are aggregate-only and pass the public-column guard before being embedded in the static site.

See the SIGIZI monitoring contract for the SQL objects, deployment order, and validation boundary.
